# Contributing

This is a small, deliberately minimal reference implementation. Contributions are welcome when they keep it that way.

- **Issues and proposals** go through GitHub Issues. A change to the bundle shape or the confirmation extension should say what consumer problem it solves.
- **Pull requests**: keep them small. No new runtime dependencies without discussion first.
- **Scraping stays a pure scrape.** No extraction rubrics, scoring, or profile-generation logic belong here.
- **Examples are fictional.** Do not add real organizations' data to `examples/`.
- **Code of conduct**: be respectful and constructive. Harassment of any kind is not tolerated.
- **Licensing**: by contributing you agree your contribution is licensed under the MIT License.

The project aims to meet the [Digital Public Goods Standard](https://digitalpublicgoods.net/standard/): open license, clear ownership, platform independence, documentation, a privacy statement, and no collection of personal data by the tool itself.
